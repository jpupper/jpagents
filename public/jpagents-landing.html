Features

Orquestación Multi-Agente

JP Agents coordina agentes de IA que trabajan en equipo sobre tu proyecto, con auto-validación y corrección automática.

🧠

Agentes en Paralelo

Crea y gestiona múltiples agentes trabajando simultáneamente en diferentes tareas del mismo proyecto. Cada uno con su propio skill, modelo y contexto.

🔄

Auto-Validación

Los agentes ejecutan el proyecto, toman screenshots y revisan logs para autocorregirse hasta que el código funcione correctamente.

🔌

Protocolo MCP

Integración nativa con Model Context Protocol para manipulación de archivos segura y estandarizada, con debugger de tráfico en tiempo real.

🏰

Agents Room 3D

Visualización en Three.js de todos tus agentes orbitando alrededor del proyecto. Cada agente es una esfera con brillo y estado en tiempo real.

⚡

Hermes Bridge

Integración directa con Hermes Agent para cada proyecto. Inicia, monitorea y controla sesiones de Hermes desde la interfaz de JP Agents.

📝

Editor con Diff

Visualiza y edita código con resaltado de sintaxis, control de cambios con Aceptar/Rechazar, diff visual, y editor con gutter + cursor info.

🗃️

Git Integrado

Realiza commits y push directamente desde la interfaz. Control de versiones sin salir del flujo de trabajo.

📊

Monitor de Agentes

Panel de control centralizado para supervisar todos los agentes activos, su estado, último avance y chat administrativo global.

🎯

Skills por Proyecto

Configura prompts de sistema globales, por proyecto o por agente. Skills reutilizables que se aplican automáticamente a nuevos agentes.

🕸️

Agentic Matrix Tree

Visualización interactiva del árbol de decisiones de cada agente con D3.js: cada llamada a herramienta, reflexión y error se renderiza en tiempo real.

🖥️

Terminal Integrada

Terminal embebida con soporte para ejecutar comandos, detener procesos, y configurar comandos de ejecución por proyecto.

🎨

Glassmorphism UI

Interfaz moderna con diseño glassmorphism, tema oscuro, animaciones suaves y tipografía Outfit. UX pensada para flujos intensivos de desarrollo.
